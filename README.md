## Herramientas que mantengo

- **[@skapxd/lint-agent](https://github.com/skapxd/lint-agent)** — Reglas de ESLint que convierten criterios de arquitectura en validaciones ejecutables para equipos y agentes de código. [Paquete npm](https://www.npmjs.com/package/@skapxd/lint-agent).
- **[@skapxd/excel2md](https://github.com/skapxd/excel2md)** — Convierte Excel a Markdown conservando fórmulas, coordenadas y dependencias entre celdas para documentación y contexto de IA. [Paquete npm](https://www.npmjs.com/package/@skapxd/excel2md).
- **[@skapxd/tree](https://github.com/skapxd/tree)** — CLI para explorar directorios, estructura de archivos y relaciones entre código y documentos sin cargar todo el repositorio como contexto. [Paquete npm](https://www.npmjs.com/package/@skapxd/tree).
- **[@skapxd/result](https://github.com/skapxd/result)** — Manejo de errores con tipos explícitos en TypeScript mediante `Result` y `trySafe`, inspirado en Rust. [Paquete npm](https://www.npmjs.com/package/@skapxd/result).

También construí **[excel2md-web](https://excel2md-web.vercel.app/)**: una aplicación para explorar fórmulas y dependencias de un Excel y exportarlo a Markdown. Procesa los archivos en el navegador, sin registro. [Ver código](https://github.com/skapxd/excel2md-web).
